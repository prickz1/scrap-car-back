------------------------------------------------------------
1. VISÃO GERAL
------------------------------------------------------------

Backend responsável por coletar, armazenar e enriquecer anúncios
de veículos do site OLX Brasil.

O processo funciona em duas etapas:
  1. Scraping das páginas de listagem → coleta URLs dos anúncios
  2. Enriquecimento → acessa cada anúncio individualmente e extrai
     os dados detalhados (marca, modelo, ano, preço, etc.)

Os dados ficam armazenados em um banco PostgreSQL rodando via Docker
e são consumidos pelo projeto de análise (scrap-car-analise).

------------------------------------------------------------
3. ORDEM DE EXECUÇÃO DOS COMANDOS
------------------------------------------------------------

PRIMEIRA VEZ (ou após resetar o ambiente):

  Passo 1 — make build
    Reconstrói a imagem Docker do backend e sobe os containers.
    Use este comando apenas quando mudar o Dockerfile ou o
    requirements.txt. Demora mais que o "make back".

EXECUÇÃO NORMAL (dia a dia):

  Passo 1 — make back
    Sobe os containers sem reconstruir a imagem.
    Equivalente a: docker compose up -d
    Sempre execute este comando antes de qualquer outro.

  Passo 2 — make scrape
    Inicia o scraper das páginas de listagem do OLX.
    Abre um terminal separado (run-scraper.bat) e começa a
    navegar pelas páginas de busca do OLX, coletando as URLs
    dos anúncios e salvando registros iniciais na tabela cars
    (com apenas os campos básicos disponíveis na listagem).

    Resultado: tabela cars populada com novos registros onde
    campos como marca, modelo, ano ainda estão NULL.

  Passo 3 — make enrich-detail
    Inicia o enriquecimento dos anúncios coletados.
    Abre um terminal separado (run-enrich-detail.bat) e acessa
    cada anúncio individualmente para extrair os dados completos
    (marca, modelo, ano, quilometragem, combustivel, cambio, etc.)

    Como funciona:
      - Processa os registros em ordem crescente de ID
      - Pula registros que já foram enriquecidos
      - Marca com 'ERRO' os anúncios que falharam (página indisponível,
        Cloudflare bloqueou, anúncio removido, etc.)
      - Pode ser interrompido e retomado a qualquer momento —
        continua de onde parou

    Resultado: tabela cars com todos os campos preenchidos
    para os anúncios que foram processados com sucesso.

  Passo 4 — make clean-scrap
    Remove da tabela os registros que são anúncios coletados
    por engano — recomendações que aparecem fora da lista principal
    do OLX e não possuem quilometragem nem dados válidos.

    Critério de remoção:
      marca = 'ERRO' AND quilometragem IS NULL

    Esses registros:
      - Foram capturados abaixo da lista principal de resultados
      - São recomendações do OLX (não anúncios reais da busca)
      - Não conseguiram ser enriquecidos pois não são anúncios normais
      - Não têm utilidade para a análise

    ATENÇÃO: este comando executa um DELETE permanente.
    Confirme antes de rodar com:
      SELECT COUNT(*) FROM cars WHERE marca = 'ERRO' AND quilometragem IS NULL;

OUTROS COMANDOS:

  make down
    Para e remove os containers (dados do volume são preservados).
    Use quando quiser liberar memória/CPU ou antes de reiniciar
    o ambiente.

  make enrich
    Atalho para o enriquecimento via Docker Compose (sem abrir
    terminal separado). Equivalente ao make enrich-detail, mas
    executa no terminal atual em vez de abrir um novo.

------------------------------------------------------------
4. RESUMO DA ORDEM COMPLETA
------------------------------------------------------------

  make build          ← apenas na primeira vez ou após mudanças no Docker
  make back           ← sobe os containers
  make scrape         ← coleta URLs e registros iniciais do OLX
  make enrich-detail  ← preenche os dados de cada anúncio
  make clean-scrap    ← remove registros inválidos (recomendações OLX)

Para ciclos seguintes (sem reconstruir):
  make back → make scrape → make enrich-detail → make clean-scrap

------------------------------------------------------------
5. ESTRUTURA DO CÓDIGO
------------------------------------------------------------

app/
  main.py                          — Inicialização da API FastAPI e
                                     criação das tabelas no banco
  core/
    config.py                      — Variáveis de ambiente (.env)
    database.py                    — Conexão async com PostgreSQL
  models/
    car.py                         — Modelo SQLAlchemy da tabela cars
  api/routes/
    ml.py                          — Endpoints REST para ML:
                                     marcas, modelos, anos, câmbios,
                                     combustíveis, direções, prever,
                                     media, anuncios, status
  ml/
    modelo.py                      — Carrega os modelos .pkl e expõe
                                     a função prever()
    dados.py                       — Carrega o DataFrame do banco em
                                     memória (cache singleton) e aplica
                                     filtros de IQR de quilometragem
  services/scraper/
    navegador.py                   — Playwright: navega pelas listagens
                                     do OLX e coleta URLs/dados iniciais
  scripts/enrichment/detail/
    main.py                        — Orquestra o enriquecimento em lotes,
                                     controla fila, sucessos e falhas
    parser.py                      — Extrai campos do JSON embutido na
                                     página de detalhe do OLX (adDetail)
    repositorio.py                 — Queries de leitura/escrita no banco

treino/
  database.py                      — Conexão síncrona com o banco para
                                     carregar dados de treino
  treinar_gb.py                    — Treina o Modelo Geral (todas as marcas)
  treinar_gb_popular.py            — Treina o Modelo Popular (marcas populares)

modelos/                           — Arquivos .pkl gerados pelo treino
  gb_modelo.pkl                    — Modelo Geral serializado
  gb_encoder.pkl                   — Encoder do Modelo Geral
  gb_modelo_popular.pkl            — Modelo Popular serializado
  gb_encoder_popular.pkl           — Encoder do Modelo Popular

6. TECNOLOGIAS
